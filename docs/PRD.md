# AI WorkDock PRD

AI WorkDock 是团队 AI 经验中台和桌面悬浮助手，用于沉淀、搜索、复制、审核和安装团队内部 Prompt、知识卡、工作流与 Codex Skill。

## MVP 范围

1. Monorepo 工程结构。
2. FastAPI 后端健康检查、登录、RBAC、Prompt 库、Skill 上传解析、管理员审核、审计日志。
3. React 管理端登录页、Prompt 列表、Skill 列表。
4. Tauri 桌面端悬浮球和托盘配置占位。
5. Docker Compose 和 CI。

## 暂缓

浏览器扩展、向量检索、私有 GitHub 仓库导入、多租户、Skill 脚本执行和自动更新放到后续版本。
